Ambient audio files (royalty-free MP3 or OGG you provide):

  universe-2.mp3   — alternate Universe ambience
  beach-1.mp3      — soft waves (Beach theme)
  beach-2.mp3      — alternate Beach ambience
  dream-1.mp3      — ethereal / fantasy (Dream Journal route)
  dream-2.mp3      — alternate Dream ambience

Place all files in this folder (public/audio/). When MP3 files are absent,
the site auto-generates gentle ambient drones using Web Audio API synthesis,
so sound works out of the box even without files.

The floating panel (bottom-right) lets you mute, change volume, and pick
"Ambience 1 / 2" for the current theme or dream route.
